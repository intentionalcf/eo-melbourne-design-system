# EO Melbourne photography system

## Creative direction
Use authentic EO Melbourne event images with large typographic blocks carrying equal visual weight. No fabricated crowds, no heavy colour tints, no stock imagery when approved event photography is available. Use the official logo unchanged.

## Components
- Desktop landing hero: equal 50/50 type and wide photo; on mobile stack copy and photo.
- Event story: 3:2 or 4:5 crop with contextual caption.
- Always provide accurate alt text; preserve human faces in responsive crops.
- Photography is for concept review until usage rights and photo consent are confirmed.
