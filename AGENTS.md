# EO Melbourne agent instructions

Before creating any EO Melbourne webpage or digital design:
1. Read `brand/tokens.css`, `brand/design.html` and `brand/voice.html`.
2. Inspect both pages in `brand/examples/` for established design patterns.
3. Use ONLY the approved colour hex values in `brand/tokens.css`. Do not introduce gradients, gold, metallics or extra colours.
4. Use only Roboto and Century Gothic typography (fallbacks may appear if fonts are not installed).
5. Use the official EO Melbourne logo exactly as supplied. Do not redraw, recolour, distort, crop or make a new anniversary mark. If the file is missing, show a labelled text placeholder, never a fabricated logo.
6. Reuse tokens and components. New styles must reference tokens rather than hard-coded replacement colours.
7. Do not invent event dates, prices, speakers, locations, registrations, sponsors, member numbers or quotes.
8. Check mobile layout, accessible labels, legible contrast and keyboard operability. For public launch, ensure all links/forms have working destinations.
9. Treat `brand/voice.html` as a DRAFT until EO Melbourne signs it off.
10. For visual changes, open `brand/design.html`, compare at desktop and mobile widths and show changes for review.


## Official logos
Use the original vector SVG artwork in `brand/assets/logos/`. Eight variants are available: horizontal/stacked × primary/black/white/inverse. Do not redraw, recolour, distort or recreate lettering. Preserve aspect ratio and adequate clear space. For dark navy surfaces use the approved white or inverse artwork, checking contrast. The original EPS uploads remain the master assets.

Photography rules: Refer to `brand/PHOTOGRAPHY.md`. Prefer supplied real EO event photographs, paired with confident oversized typography. Never invent or recolour official EO logos.
