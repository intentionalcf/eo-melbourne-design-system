# EO Melbourne: three modern design directions

Open `index.html` locally in a browser. Use the tabs to compare the three directions.

1. **Executive minimal:** restrained, premium, useful for portals and regular communications.
2. **Bold editorial:** dramatic, event-first, campaign driven.
3. **Confident hybrid (recommended):** flexible everyday system with striking flagship moments.

## Non-negotiable brand rules
- Colours: `#0C0C31`, `#5258E2`, `#33388F`, `#99A1FF`, `#FFFFFF` only.
- Typography: Century Gothic for headlines, Roboto for body; use authorised font delivery in production.
- The visual wordmark in the HTML is a text placeholder, **not the official EO logo**. Replace with supplied approved logo asset.
- Illustrative copy and event claims are placeholders requiring EO Melbourne approval.
- Inspiration is at the layout and visual-system level; don't copy third-party logos or exact designs.

Once a direction is approved, move its layout rules into shared CSS/components and keep `design.html` as the visual catalogue. Do not treat this exploration as a production website.
